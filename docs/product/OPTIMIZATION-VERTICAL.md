# Bonded-group confidentiality pack

Quiet Super-admin checklist and forum-moderator review for a Performance Optimization Group. Badge Shared 1-1.117. Not Shared 2.

## What stays dark

`vertical_pack_optimization` defaults off. Leave `VERTICAL_PACK_OPTIMIZATION` unset so the rehab pilot stays as it is. Super-admin can still open `/admin/verticals/optimization`. Set the flag to 1 / true / on / yes to apply the copy skin, confidentiality defaults, and commitment board on Performance Optimization Group desks. Organization type `performance_optimization_group` recommends the pack only. It does not turn the env flag on.

Rehab organizations never receive this pack. Flag-off leaves Returning Home NWA unchanged.

There is no new ribbon item. Same Desk spine. No second app. No film rewrites.

## Pack templates

Downloads on the Super-admin checklist:

1. Confidentiality defaults
2. Non-clinical copy note
3. Forum-moderator review checklist
4. Sponsorship and public go-to-market deferral

Downloads stay drafts. A download is not a signature and not a public launch.

The same review list lives in `partner-kit/forum-moderator-review.md`.

## Confidentiality defaults

- Join is invitation-only. Men enter an invite code. Do not post the code on a public page.
- Leaders see completion flags, not written answers.
- Leader notes are not exported by default.
- When the pack is on for that organization, father chrome omits the Rehab participation label.

## Commitment board

Practice completion flags (completed, not yet, dismissed, stale) appear as peer follow-through. No grades. No answer text.

## Sponsorship

The organization funds facilitator capacity. There are no paid participant tiers. The father stays free.

## Go-to-market rule

There is no public go-to-market for this pack until the forum-moderator review checklist is signed off.
